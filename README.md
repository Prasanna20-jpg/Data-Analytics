# Data Immersion & Wrangling

## Objective
The objective of this project is to understand, clean, and prepare raw data for analysis using Python and Pandas.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Tasks Performed
- Imported and explored the dataset
- Identified missing values and duplicates
- Cleaned inconsistent data
- Converted date formats
- Performed basic feature engineering
- Detected and handled outliers
- Created an analysis-ready dataset

## Files Included
- data_cleaning.ipynb
- cleaned_superstore.csv
- data_dictionary.xlsx

## Outcome
Successfully transformed raw data into a clean and structured dataset suitable for further analysis and visualization.
